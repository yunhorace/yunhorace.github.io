# Personal GitHub Pages Site

Welcome to your personal portfolio website! This is your GitHub Pages site, hosted at `https://yunhorace.github.io`.

## Quick Start

Your site is live and ready to customize. Make changes and push them to the `main` branch to see updates instantly.

## Customization Guide

### 1. Update Your Information

**In `index.html`:**
- Replace `Yunho Race` with your name in the navbar and footer
- Update the hero section text with your own welcome message
- Edit the About section to tell your story
- Replace the email address and social media links in the Contact section

### 2. Add Your Projects

In `index.html`, find the Projects section and:
- Replace `Project One`, `Project Two`, `Project Three` with your actual project names
- Update project descriptions
- Replace technology tags with the real technologies you used
- Add links to your project repositories or live demos

### 3. Customize Colors

In `style.css`, update the CSS variables at the top:
```css
:root {
    --primary-color: #667eea;      /* Change this to your primary color */
    --secondary-color: #764ba2;    /* Change this to your secondary color */
    --text-color: #333;            /* Text color */
    --light-bg: #f7fafc;           /* Light background */
}
```

### 4. Update Social Links

Find the contact section in `index.html` and update:
- Email: `mailto:your-email@example.com`
- GitHub: `https://github.com/yunhorace`
- LinkedIn: `https://linkedin.com/in/yunhorace`
- Twitter: Update the URL

## How to Deploy

1. Make your changes locally or directly in GitHub
2. Commit your changes
3. Push to the `main` branch
4. Your site updates automatically in a few seconds!

## Adding More Sections

To add new sections:
1. Add a new `<section>` element in `index.html`
2. Add corresponding CSS in `style.css`
3. Update the navigation menu to include a link to your new section

## Tips

- Keep your About section concise and engaging
- Use high-quality project descriptions
- Include a photo or avatar for a personal touch
- Update your projects regularly to show current work
- Test responsiveness by resizing your browser
